# 快传通信协议

> 适用版本：v1.0.0
> 本文描述快传各端之间的通信格式，便于第三方实现兼容客户端（如安卓、iOS、macOS 版）。

## 1. 端口

| 端口 | 协议 | 用途 |
|---|---|---|
| 9000 | TCP | 电脑互传 |
| 9001 | UDP | 设备搜索 |
| 9002 | HTTP | 手机互传网页 |

## 2. 设备搜索（UDP 9001）

1. 发送方向 `255.255.255.255` 及各网卡的 `/24` 子网广播地址发送报文 `KUAICHUAN2?`（ASCII，11 字节）。
2. 已开启接收的设备回复 UTF-8 JSON：`{"name": "电脑名", "port": 9000}`。
3. 发送方收集 1.5 秒内的回复，按 IP 与电脑名排除本机。

## 3. 电脑互传（TCP 9000）

### 3.1 消息格式

控制消息统一为：**8 字节大端无符号整数（JSON 长度）+ UTF-8 JSON**。
文件内容在对应的文件头消息之后以原始字节紧随发送，长度等于文件头中的 `size`。

### 3.2 会话流程

| 序号 | 方向 | 内容 | 说明 |
|---|---|---|---|
| 1 | 接收 → 发送 | `{"name": 电脑名, "dir": 保存路径}` | 握手。发送方若发现 `name` 与本机相同，立即断开（防止发给自己） |
| 2 | 发送 → 接收 | `{"from": 电脑名, "count": 文件数, "total": 总字节}` | 本次任务概要 |
| 3 | 发送 → 接收 | `{"name": 相对路径, "size": 字节数}` + 文件内容 | 每个文件一次；路径分隔符统一为 `/` |
| 4 | 接收 → 发送 | 1 字节 `0x01` | 该文件已完整写盘 |
| 5 | 发送 → 接收 | `{"name": ""}` | 结束标记 |
| 6 | 接收 → 发送 | `{"saved": 保存路径, "count": 文件数, "total": 总字节}` | 回执 |

### 3.3 约束

- 接收方必须拒绝解析后落在保存目录之外的路径（如 `../`）。
- 连接中断时，接收方删除当前未写完的文件。
- 建议读写块大小 4 MB；连接超时 8 秒，读写超时 30 秒。

## 4. 手机互传（HTTP 9002）

所有请求都必须携带查询参数 `k`（口令），口令每次开启服务随机生成，不匹配返回 `403`。

| 方法 | 路径 | 参数 | 返回 |
|---|---|---|---|
| GET | `/` | `k` | 手机端网页 |
| GET | `/list` | `k` | `{"files": [{"p": 相对路径, "s": 字节数}]}`，列出共享文件夹 |
| GET | `/dl` | `k`, `p`（相对路径） | 文件内容，`Content-Disposition: attachment` |
| POST | `/upload` | `k`, `name`（文件名） | 请求体为文件原始内容；返回 `{"ok": true, "saved": 实际文件名}` |

- 上传只取 `name` 的文件名部分；同名文件自动改名为 `名称 (1).扩展名`，不覆盖。
- 下载路径越界返回 `403`，文件不存在返回 `404`。
